# Code of Conduct

Be respectful and constructive.

## Expected behavior
- Treat all contributors, server owners, and users with respect.
- Provide feedback in a helpful and non-abusive way.
- Keep discussions focused on the project.

## Unacceptable behavior
- Harassment, hate speech, discrimination.
- Threats, doxxing, or sharing private information.
- Spamming or disruptive behavior.

Maintainers may remove comments or close issues/PRs that violate this policy.
